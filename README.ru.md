# Chart Lines in DOM для MotiveWave

[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
![Только отображение](https://img.shields.io/badge/ордера-не%20отправляет-blue)
![MotiveWave 7.1.1](https://img.shields.io/badge/MotiveWave-7.1.1-informational)

[MotiveWave](https://www.motivewave.com) не умеет показывать линии, которые вы рисуете на графике, в **стакане** (DOM). Этот индикатор умеет:
каждая **горизонтальная линия** графика превращается в **цветную заметку на той же цене** в стакане, цвета линии, и следует за линией, когда вы её двигаете, добавляете или удаляете.

Уровни вы рисуете один раз на графике, а торгуете, глядя на стакан, — и видите их там.

![Заметки в стакане](docs/dom-notes.jpg)

> **Только отображение.** Обычный *Study* MotiveWave. У него нет доступа к ордерам: он **не может выставить, изменить или отменить ордер**. Он только читает график и пишет заметки в стакан.

## Что вы получаете

| На графике | В стакане |
|---|---|
| горизонтальная линия на 31255.00, зелёная | зелёная ячейка «31255.00» в колонке **Notes** на этой строке |
| вы перетащили линию на 31267.50 | ячейка переехала на 31267.50 |
| вы удалили линию | ячейка исчезла |
| вы сменили цвет линии | ячейка сменила цвет |
| две линии на одной цене | одна ячейка (цвет первой линии) |

Если *Ticks/Row* больше 1, заметка стоит на строке стакана, в которую попадает цена. Уже нарисованные линии появляются в течение секунды после добавления индикатора.

## Установка

1. Скачайте `DomLines.jar` из [последнего релиза](../../releases/latest).
2. Положите файл в папку **`MotiveWave Extensions`** в вашей домашней папке (MotiveWave сканирует её автоматически; на macOS это `~/MotiveWave Extensions` — создайте папку, если её нет).
3. Перезапустите MotiveWave (или подождите около 10 секунд: новый jar он подхватывает сам). Индикатор появится в **Study → Alex Indicators → Chart Lines in DOM**.

> Проверено на **macOS, MotiveWave 7.1.1**, фьючерсы CME (MNQ). Jar — обычная Java и должен работать и на Windows, но это не проверялось.

## Настройка (один раз)

1. Откройте график, линии которого нужны, затем **Study → Alex Indicators → Chart Lines in DOM → Add** (один раз на график). Сохраните график как *Template*, чтобы индикатор был на каждом новом графике.
2. В шапке стакана нажмите **+** и поставьте галочку **Notes**. Колонка Notes **по умолчанию выключена** — на этом шаге чаще всего спотыкаются. Перетащите заголовок **Notes** поближе к **Price** (или расширьте стакан), чтобы заметки были рядом с лестницей цен.
3. Стакан должен быть **связан с графиком** (тот же инструмент, тот же цвет связи). Несвязанный стакан заметки графика не показывает.

Это всё.

## Настройки

Нажмите **шестерёнку** рядом с *Chart Lines in DOM* в легенде графика — там три настройки ниже (или Study → *Chart Lines in DOM* → Properties):

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Show chart lines in the DOM | вкл | Выключить всё, не удаляя индикатор (заметки очищаются). |
| Show the price in the note | вкл | Цена как текст заметки. Выкл = просто цветная ячейка. |
| Use the colour of each line | вкл | Выкл = один фиксированный **Note colour** для всех линий. |

## Ограничения

- Только **горизонтальные** линии (две опорные точки на одной цене). Наклонные линии, вертикальные, лучи с наклоном, уровни Фибоначчи и другие рисунки в стакан не попадают.
- Линии, которые вы **скрыли** на графике, остаются в стакане (признак скрытия пока не читается).
- Рисунки графика читаются через **внутренности MotiveWave**, потому что в SDK для этого нет API. Проверено на **MotiveWave 7.1.1**. После обновления платформы индикатор может перестать находить линии; тогда он ничего не делает (стакан и график он не ломает) и пишет причину в журнал. Всё, что касается стакана, использует публичный SDK.
- Заметки принадлежат графику. Если стакан связан с другим графиком или инструментом, там они не показываются.

## Если не работает

| Симптом | Что проверить |
|---|---|
| Заметок нет совсем | Стоит ли галочка **Notes** в меню **+** шапки стакана? Связан ли стакан с графиком? Добавлен ли индикатор именно на *этот* график? |
| Заметки есть, но далеко от лестницы цен | Перетащите заголовок **Notes** к **Price** или прокрутите стакан: заметки видны только на видимых строках. |
| Работало до обновления MotiveWave | Посмотрите журнал (ниже). Внутренности платформы могли измениться — создайте issue с версией MotiveWave и строкой из журнала. |
| Одной линии нет | Поддерживаются только горизонтальные линии; обе опорные точки должны быть на одной цене. |

Журнал: `~/Library/MotiveWave/DomLines/audit-<дата>.log` (короткая строка на каждое изменение, например `16 line(s) on the chart …`, `notes +16`).

## Как это устроено

Стакан умеет показывать *заметки*, а SDK позволяет индикатору их добавлять (`DataContext.addNote`). Чего SDK не даёт — списка рисунков графика, поэтому индикатор находит их через reflection (по *форме* данных, а не по обфусцированным именам) и опрашивает каждые 300 мс. Подробно, с доказательствами и устройством: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (на английском).

## Сборка из исходников

```bash
bash build.sh            # сборка + 21 тест -> build/DomLines.jar
bash build.sh install    # плюс копирует в ~/MotiveWave Extensions (подхватывается без перезапуска)
```

Нужен JDK 17+ и из вашей установки MotiveWave — `mwave_sdk.jar` и файлы `javafx.*.jar` (в репозиторий они не входят). Пути можно задать переменными `MW_SDK`, `MW_EXT`, `JAVA_HOME`.
